### Test version — for trying on hardware

This is a **pre-release** for testing. The internal updater and ProsperoStore leave it alone; download `PPSA11019-test.zip` by hand. Please report what you find on the [Shortcuts issue](https://github.com/bornaradusin/Home5/issues/3).

### What's new

- **Shortcuts.** In Options › Shortcuts, set up a controller **combo** (two or more buttons held together) or a **sequence** (buttons in order) that runs a scene, a script or a device in Home Assistant. A small background part reads the controller **while a game is running** and fires it, so you never leave the game. Each shortcut has its own confirmation: flash the light bar, a console notification, or both.
- **Keep L3 + R3 in a combo.** Both sticks pressed is a safe base a game won't trigger by accident.

### How it works

- The background reader lives inside the system's own `SceShellUI`, the only place a payload can read the controller while a game is in front. Home5 hands it your shortcuts and sign-in through `/data/homebrew/PPSA11019/`; it calls Home Assistant's REST API directly.
- Load the reader payload (`PPSA11019-reader.elf`) after Home Assistant is set up in the app. It reads the controller until you reboot or stop it.

### Known limits

- Tested on **PS5 Pro firmware 10.20** only. Other firmwares are unconfirmed — reports welcome.
- Won't run alongside the DualSense overlay, Common FPS or SimpleFPS (one `SceShellUI` injector at a time).
- A session token can expire; a long-lived Home Assistant token keeps the reader working longest.
